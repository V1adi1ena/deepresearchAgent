## 当前使用版（三条主线）

**Deep Research Agent｜个人项目**

**项目描述：** 面向复杂问题的多智能体研究系统，支持问题拆解、并行检索、研究记忆共享及报告审查，生成关联信息来源的研究报告。

**技术栈：** Python、asyncio、SQLite、NumPy、Sentence Transformers、TextRank

- **异步编排与容错：** 基于 asyncio 与 Semaphore 实现 DAG 依赖调度及并发控制，将上游研究结果注入下游任务上下文；针对子任务失败设计有限重试与重规划机制，保留成功结果以减少重复执行；通过全局截止时间、汇总时间预留及部分结果返回处理超时。
- **共享记忆与上下文优化：** 基于 SQLite 与 NumPy 构建跨 Agent 共享记忆，通过语义检索与去重复用中间研究结果；结合 Embedding 相关性筛选、TextRank 关键句提取与分级摘要控制上下文规模，保留任务、来源与证据片段的关联，支持后续研究与报告生成。
- **证据审查与定向修复：** 设计 Red–Blue 审查机制，输出包含问题位置、类型及证据的结构化反馈，通过补充检索、事实修正或删除无依据结论完成定向修复；结合修复后复核、版本记录与回退控制修改过程，并设置审查轮数及调用预算，控制迭代开销。

使用说明：本版不填写未测量的效果指标；描述对应项目实现，不代表已经掌握全部追问。有限片段与审查预算是设计取舍，不承诺所有研究问题正确或所有问题均被修复。
