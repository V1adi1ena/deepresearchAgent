## 当前修改

1. 规划保留 preferred_domains、精确版本和时间范围；提示明确每个子任务只有两次搜索、两次网页读取，避免用一个任务包揽所有对象，再另设泛泛合成任务。当前/最新问题加入运行日期。
2. 博查请求保留较长 summary 与 datePublished；域名偏好通过 include 参数落实到接口，并在本地核对域名及子域名，防止搜索语法被忽略后偷偷使用外站。其他后端仍可使用查询约束和本地过滤，不宣称具备同样的服务端过滤能力。
3. 对明确错版本和偏离时间范围的标题保留剔除原因；先比较目标版本相关性，再考虑域名偏好。较晚发表但可能回顾旧版本的材料不一律删除，而是携带时间风险标记。
4. 每个子任务最多两次搜索与两次网页读取；自动阅读一个候选页面后，将逐字片段、来源 URL 与证据类型一并返回。读取失败消耗预算并保留原因，不升级为已读正文。
5. 表格提取保留行与列分隔；长页面按查询选择原文窗口，避免只保留页首。完整工具结果保存在任务轨迹，来源记录最多保留 2,000 字符证据片段。
6. 生成与审查区分 search_snippet、search_summary、page_excerpt；审查读取实际引用来源的已存片段及日期，不再只看前 300 字。域名偏好、网页成功读取、模型自评分均不等于事实正确。
7. 检测实际遇到的 WAF 脚本页，不当作文章正文；每个审查维度最多返回三项高优先级问题，避免有限输出预算被冗长清单耗尽。该清单不是全量错误统计。

博查字段依据：[官方适配器](https://github.com/bocha-ai/dsh-web-search-bocha/blob/main/README.md)、[官方解析代码](https://github.com/BochaAI/open-webui-Bocha/blob/main/backend/open_webui/retrieval/web/bocha.py)。include 还经过实际接口探测：限定 openai.com 与 anthropic.com 时，返回网址分别位于对应域名；接口域名过滤本身不保证结果符合目标版本，因此仍需本地筛选。

## 验证边界

- 标题/版本筛选与词项窗口是启发式处理，不是语义蕴含验证；未知版本名、未标注日期和上下文依赖都可能影响判断。
- page_excerpt 指读取到了页面片段；arXiv 摘要页不等于论文全文，发布日期可能是平台维护日期。
- 当前 browser 提取 HTML；PDF 会明确返回不支持，不能冒充已读全文。
- 研究题覆盖、引用是否支撑结论与修复是否正确，需要逐条核对；技术检查通过和增加正文数量均不能代替质量验收。
