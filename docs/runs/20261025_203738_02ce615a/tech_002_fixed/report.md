# AI 芯片市场格局与竞争力分析：NVIDIA、AMD、Intel 与华为昇腾、寒武纪

> **证据说明（必读）**：本次检索仅返回 5 条来源，全部为中文财经/科技媒体与自媒体的**摘要级片段**，且内容高度集中于**中国市场与国产厂商梯队**。关于 NVIDIA、AMD、Intel 的产品规格、出货量、财务数据、训练/推理基准测试，**检索结果中没有任何实质性证据**。因此本报告在涉及这三家厂商的部分，只能给出**结构性分析与证据缺口标注**，不做数值化断言。凡属分析推断而非来源直述的内容，均以「〔推断〕」标记。

## 一、执行摘要

1. **需求结构正在从训练主导向推理主导迁移。** 来源称 2026 年 AI 基础设施正经历"从训练驱动向推理驱动的结构性转变"，推理计算需求已达训练需求的 **4–5 倍**，推理算力整体市场空间**超过 3000 亿元人民币** [s_6982add1fb8c]。这是理解各厂商竞争力分化的最重要背景变量。
2. **中国市场已形成清晰的国产梯队。** 华为昇腾被定位为"第一梯队/绝对龙头"，特征是"全栈 + 集群 + 生态 + 产能碾压"；寒武纪为"第二梯队绝对龙头"，仅次于昇腾，领先海光、昆仑芯、壁仞、沐曦 [s_947b4a3f0d39]。
3. **份额格局出现标志性变化。** 2025 年中国 GPU 市场中华为与英伟达**并列第一**，寒武纪、海光、平头哥、昆仑芯"多元并进" [s_d2fdf7b423fe]。同源引述复旦大学刘典的判断："英伟达依赖时代已经结束"，代之以国内厂商为核心的多方生态 [s_d2fdf7b423fe]。
4. **推理专用化成为国产厂商的产品路线。** 昇腾推理产品线被列为 910B/C、**950PR（推理专用）**、950DT（2026Q4），并已进入"大规模量产/亿级订单"阶段 [s_71a7b2f7b745]。
5. **最大证据缺口**：AMD 与 Intel 在本次检索中**完全没有出现**；NVIDIA 仅以"并列第一"和被替代的叙事出现，无产品层面信息；寒武纪的具体产品型号与性能数据亦被截断。因此"训练 vs 推理"的五方横向对比，**只能对华为、寒武纪给出有证据的定位，其余三方为空白**。

## 二、背景：为什么"训练 vs 推理"是本次分析的主轴

来源给出的关键量化判断是：推理计算需求为训练需求的 4–5 倍，推理算力市场空间超 3000 亿元 [s_6982add1fb8c]。这一条数据本身构成了市场格局分析的基本框架：

- **训练场景**的经济特征是资本密集、集群规模大、软件栈锁定强、单客户采购集中（云厂商与国家级算力中心）。来源对华为昇腾"全栈 + 集群 + 生态 + 产能碾压"的描述 [s_947b4a3f0d39]，正对应训练场景所需的能力组合〔推断〕。
- **推理场景**的经济特征是成本敏感、碎片化、对能效与单位 token 成本敏感、部署形态多样（云、边缘、私有化）。来源中"推理专用"芯片（昇腾 950PR）与"通用计算到推理专用"的行业观察标题 [s_71a7b2f7b745][s_6982add1fb8c]，说明产业已开始为推理场景做专用化分工〔推断〕。
- **
