# 2024 主流大模型三维对比：证据不足，无法完成

## 结论先行
现有证据**不足以**支撑 GPT-4o、Claude 3.5、Gemini 1.5、Qwen2.5 在中文推理、代码生成、长上下文三维度的对比。四者中仅 Qwen2.5 系列有可引用的原始技术报告，其余三家的官方基准、上下文规格、架构细节均未取得原文。

## 可支持的事实（仅 Qwen2.5 线）
- **Qwen2.5-Coder**（arXiv:2409.12186，v1 2024-09-18，v3 2024-11-12）：0.5B–32B 六档，基于 Qwen2.5 架构，在 **5.5 万亿 token** 代码语料上继续预训练，采用数据清洗、可扩展合成数据、平衡数据混合；覆盖 10+ 代码基准（生成/补全/推理/修复），宣称同规模 SOTA [s_8d9be8fd8248]。
- **Qwen2.5 技术报告**（arXiv:2412.15115，v1 2024-12-19）仅确认存在，摘要细节未取到 [s_6d87a35754c3]。

## 证据缺口（逐项）
- **GPT-4o**：无正式技术报告；检索返回的是 NLPCC 中文隐喻生成论文 [s_7bb974b94611] 与四级作文页 [s_cdad4967f651]，与问题无关，未获任何基准分数。
- **Claude 3.5 / Gemini 1.5**：未检索到官方 model card 或技术报告。虎嗅测评页正文被 WAF 脚本占据，无可读内容 [s_d42895bd5513]。
- **中文推理（C-Eval/CMMLU）**：四模型分数全部缺失。
- **长上下文**：Claude 200K、Gemini 1M、GPT-4o 128K 等数值仅见于 2026 年聚合站/博客 [s_5cda1bca9019][s_0bb2ec1ac306]，属 later_publication，且混入 Gemini 3.5/Claude 4 等错版本，不可用于 2024 版本对比。
- **架构路线**：MoE/GQA、RoPE 外推等无原始出处；仅二手博客列出 Qwen2.5-Coder 的 KV 头数等参数表 [s_0583dfaa9b80]，未经原文核实。

## 技术路线差异
仅能就 Qwen2.5-Coder 说明"代码专用继续预训练 + 合成数据"路线 [s_8d9be8fd8248]；其余三家路线差异**无证据**，不作推断。

## 建议补证
读取 arXiv:2412.15115 全文、Anthropic Claude 3.5 Sonnet model card、Gemini 1.5 report PDF、OpenAI GPT-4o System Card（2024-08-08）及 SuperCLUE 2024 中文榜原始报告。

**总体置信度：0.30**（仅 Qwen2.5-Coder 一条事实可靠，三维对比无法成立）

**关键来源**：arXiv:2409.12186（唯一实质证据）；arXiv:2412.15115（仅存目）；其余检索结果不相关或为错版本二手内容，已排除。
