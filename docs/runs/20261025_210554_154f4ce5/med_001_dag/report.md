# 2023–2024 mRNA癌症疫苗临床进展综述

## 技术原理
mRNA疫苗编码肿瘤相关抗原或新抗原，经脂质纳米颗粒（LNP）递送进入树突状细胞等抗原呈递细胞，翻译呈递后激活CD8⁺细胞毒性T细胞与CD4⁺辅助T细胞，并诱导体液应答[s_2da0be08dbbc][s_4f6fcc4058a6]。5′帽、UTR、poly(A)尾及核苷修饰（如假尿苷、m5C）提升稳定性与翻译效率、抑制先天免疫过度激活[s_bf076cc3716d]；LNP兼具递送与佐剂功能[s_2da0be08dbbc]。

## 关键试验数据
- **KEYNOTE-942（mRNA-4157/V940+帕博利珠单抗，黑色素瘤）**：随机2b期，切除后高危IIB–IV期黑色素瘤，n=157；复发或死亡风险降低44%（HR=0.561，95%CI 0.309–1.017，p=0.053），18个月无复发生存率79.0% vs 62.2%[s_378637f3358e][s_6ef517ea39d3][s_f135fecfcfe0]。已获FDA突破性疗法认定[s_7e891e46e3a1]，并启动III期。
- **Autogene cevumeran（BNT122，胰腺导管腺癌）**：术后患者约50%（8/16）产生新抗原特异性T细胞，应答者中位无复发生存未达到 vs 13.4个月（HR≈0.08）；毒性以短暂发热为主。样本量小（n=16），数据待同行评审确认。
- 总体安全性：以轻中度注射部位反应与流感样症状为主[s_4f6fcc4058a6]。

## 挑战与缺口
1. **疗效证据有限**：2024年尚无III期疗效读出；KEYNOTE-942的p值未达0.05，统计学显著性存疑。
2. **样本量与证据等级**：关键数据多来自2b期或小样本研究，部分安全性数据仅见于会议摘要。
3. **技术瓶颈**：免疫原性调控、递送效率与生产规模化仍是难点[s_7f427fd44058]。
4. **证据缺口**：未获取完整NCT编号、ORR等量化终点；"2025商业化元年"仅为券商二手预测[s_5c3a644d2e16]，不宜作为结论。

**总体置信度：0.70**（机制与KEYNOTE-942数据较可靠；胰腺癌数据及商业化预测证据薄弱）
