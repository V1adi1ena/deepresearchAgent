# GLP-1受体激动剂减重外应用评估

## 心血管保护（证据最强）
- **司美格鲁肽**：SELECT试验（非糖尿病超重/肥胖+CVD）显示MACE风险降低约20%[s_c52e943773a4][s_2350feaaafdc][s_4095ddfd26a9]；关于“获益部分独立于体重下降”的机制声明，现有来源未提供直接证据支持，标注为**未经证实**。SUSTAIN 6/PIONEER 6在T2D中降低MACE，汇总分析显示心肾获益跨CVD状态、BMI及HbA1c水平一致[s_de957f2966e4][s_e1c9df85bab8]。
- **替尔泊肽**：Meta分析提示超重/肥胖无糖尿病人群中GLP-1 RA及替尔泊肽降低MACE与全因死亡[s_01082c42a9dd][s_374bfeef9f27]。
- **缺口**：SURPASS-CVOT具体结果数值、各试验精确HR/CI未获取；替尔泊肽在非糖尿病肥胖人群的硬终点RCT证据有限。

## 认知功能（证据偏阴性/早期）
- **司美格鲁肽**：III期EVOKE/EVOKE+（早期症状性AD）**未能延缓AD进展**，主要认知终点未达[s_5c2ea559487d][s_6388952ac807]；观察性靶试验模拟提示AD诊断风险方向性降低[s_ded0b30184df]。
- **利拉鲁肽**：IIb期RCT（轻中度AD）已开展[s_33d8348e975e][s_f4232a439b24]；系统综述/Meta分析汇总利拉鲁肽与艾塞那肽认知结局[s_c50e62313c9b]。
- **替尔泊肽**：无认知/AD/PD的RCT证据，仅机制综述与观察性数据[s_d517f172d0a2]。
- **缺口**：EVOKE效应量与安全性细节未获取；PD无大型RCT。

## 成瘾治疗
**检索证据中无成瘾治疗相关数据**，无法评估。

## 结论
心血管保护证据最充分（司美格鲁肽硬终点明确，替尔泊肽以Meta分析为主）；认知领域III期结果为阴性，神经保护仍属假说；成瘾治疗缺乏证据。

**总体置信度：0.65**
