# mRNA癌症疫苗（2023–2024）进展综述

## 摘要
现有证据仅支持有限结论：mRNA癌症疫苗被视为肿瘤免疫治疗的重要方向，2024–2025年进入“爆发期”，在黑色素瘤、胰腺癌、脑癌等难治肿瘤中“取得重大成果”[s_c659f005e2b1][s_34b241935a4b]。但检索结果多为摘要或媒体转述，缺乏可核验的2023–2024年具体试验数据。

## 支持性发现
- **技术原理**：利用mRNA使免疫系统识别并攻击癌细胞[s_5c3a644d2e16][s_c659f005e2b1]；mRNA技术在新冠疫苗中的成功推动了癌症疫苗研发[s_928ce48e3853]。
- **时间判断**：中信证券研报认为2025年或为mRNA肿瘤疫苗“商业化元年”[s_5c3a644d2e16][s_472738d89710]；另有报道称2029年或正式进入临床[s_c659f005e2b1][s_34b241935a4b]。二者并不矛盾：前者指商业化起点，后者指广泛临床应用。
- **挑战**：安全性/实际应用仍待深思[s_472738d89710]；《实用肿瘤杂志》2023年综述主题即包含“挑战及展望”[s_928ce48e3853]。

## 证据缺口
- 无具体试验编号、样本量、疗效（如ORR、OS）或安全性数据。
- 2023–2024年试验进展缺乏一手来源，多为2025年视角的二手报道。
- 技术原理细节（抗原设计、递送系统）未提供。
