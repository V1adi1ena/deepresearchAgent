# AI 芯片市场格局：训练与推理竞争力比较

## 摘要
现有证据仅覆盖中国厂商的梯队排序与推理市场趋势，**缺乏 NVIDIA、AMD、Intel 的可比数据**，因此无法完成五方横向竞争力比较。可支持的结论限于：华为昇腾居国产第一梯队，寒武纪为第二梯队龙头；推理需求已显著超过训练需求。

## 有证据支持的发现
- **国产梯队**：华为昇腾为第一梯队（全栈、集群、生态、产能领先）；寒武纪为第二梯队龙头，领先海光、昆仑芯、壁仞、沐曦 [s_947b4a3f0d39]。
- **推理产品**：昇腾核心推理产品包括 910B/C、950PR（推理专用）、950DT（2026Q4）[s_71a7b2f7b745]。
- **需求结构**：2026 年 AI 基础设施由训练驱动转向推理驱动，推理需求为训练的 4–5 倍，推理算力市场空间超 3000 亿元 [s_6982add1fb8c]。
- **市场格局**：2025 年中国 GPU 市场华为与英伟达并列第一，寒武纪、海光、平头哥、昆仑芯多元并进 [s_d2fdf7b423fe]。

## 证据缺口与矛盾
- 无 NVIDIA/AMD/Intel 的训练或推理性能、份额、生态数据，五方比较无法成立。
- 寒武纪具体产品与训练场景表现未提供；"第二梯队龙头"仅为单一来源判断。
- 华为与英伟达"并列第一"的口径（出货量/份额/收入）未说明，且与"英伟达依赖时代结束"的定性表述存在张力，无法核实 [s_d2fdf7b423fe]。
- 中商情报网前五企业名单被截断，未采信 [s_574028e53683]。
