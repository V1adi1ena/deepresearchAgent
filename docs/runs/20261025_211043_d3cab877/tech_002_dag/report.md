# AI芯片市场格局：训练与推理竞争力分析

## 核心结论
NVIDIA在训练侧占据主导地位（大多数AI训练集群由NVIDIA GPU支持）[s_11323cdd534f]，推理侧约80%份额但面临稀释（2028年或降至50%）[s_dbe23d84369a][s_11323cdd534f]。AMD、Intel在检索证据中缺乏可引用的份额或规格数据，竞争力无法评估。中国厂商呈"国内替代"格局：华为、海光、寒武纪合计约占中国AI加速卡90%份额[s_396bb868b852]，昇腾在20余城市智算中心占79%[s_bb4656a15302]。

## 分场景比较
- **训练**：主流训练集群基本由NVIDIA GPU支撑，例外为Google TPU、AWS Trainium等云厂商自研ASIC[s_11323cdd534f][s_d92abb3a1d62]。昇腾经深度优化可在华为自有大模型上训练，但外部大厂采用存疑[s_6373a1568caf]。
- **推理**：NVIDIA约80%份额，格局"尚未定局"[s_dbe23d84369a]；推理需求占比已超预期达40%[s_546856fa8f96]。
- **国产规格（二手，口径不一）**：昇腾910约512 TOPS@INT8/256 TOPS@FP16；思元590约512 TOPS@INT8[s_303619dab726]。昇腾910B的FP16被称优于NVIDIA H20（头条转述，非一手）[s_43af149146d9]。
- **落地**：寒武纪参与中国移动哈尔滨智算中心，部署1.8万张加速卡[s_bb4656a15302]；2024年国产AI芯片出货同比增420%，昇腾、寒武纪贡献78%增量（工信部数据转述）[s_38ca17408e4f]。

## 证据缺口
- 缺H100/H200、MI300X、Gaudi 3、910B、思元590的一手规格（FP8/FP16、HBM、带宽、TDP）。
- 缺MLPerf实测；Intel Gaudi 3数据几乎空白；AMD竞争力无证据。
- 份额多为二手转述，全球/中国、出货量/金额口径混杂，需IDC/TrendForce原文核实。
- 软件生态（CUDA/ROCm/oneAPI/CANN/BANG）成熟度仅为方向性判断。
